# Tip Calculator

A simple Tip Calculator built with **React**, **TypeScript**, and **Sass**. This app allows users to calculate the tip for a bill, with the option to split it among multiple people. It includes dynamic calculations and is fully responsive.

## Features
- Enter a bill amount.
- Select a tip percentage.
- Split the bill between multiple people.
- Responsive design with Sass.
- Input validation (no negative numbers).
